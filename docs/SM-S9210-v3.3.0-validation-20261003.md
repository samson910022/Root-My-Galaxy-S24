# SM-S9210 KernelSU v3.3.0 candidate validation

## Result

One end-to-end Shizuku-mode install succeeded on a physical SM-S9210 on
2026-10-03. This validates one run of the exact e1q candidate pair, not
repeatability or the full post-install regression suite. After the install,
the subsequent evidence collection used read-only checks and did not reboot or
otherwise modify the phone.

## Validation scope

- Proven: one Shizuku app flow obtained bootstrap root, loaded KernelSU, and
  passed the app's KernelSU control-channel check on this exact firmware.
- Not established: repeatability, reboot persistence, Manager UI recognition,
  `resetprop` regressions, or the temperature reached during the run.
- The support-feed e1q artifact remains unchanged until the remaining
  acceptance checks are completed; this note records the candidate test only.
